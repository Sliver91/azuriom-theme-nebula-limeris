## Ce que voit le joueur

- Une barre de navigation, puis le nom du serveur en grand avec la phrase d'accroche, le bouton pour rejoindre le serveur (il copie l'adresse) et le bouton pour voter.
- Trois chiffres : joueurs en ligne, votes du mois, version du jeu.
- Les actualités, l'objectif de votes, les meilleurs voteurs du mois, la liste des serveurs et un bloc Discord.
- Un rappel « Rejoindre en une minute » en trois étapes.
- Un mode clair et un mode sombre. Les fonds d'univers s'affichent en mode sombre.
- Les pages d'Azuriom et des plugins (vote, boutique, connexion…) prennent les mêmes couleurs et les mêmes blocs.

## Prérequis

- Azuriom 1.2 ou plus récent.
- Le plugin **Vote** est facultatif : sans lui, le bouton « Voter », l'objectif et le classement ne s'affichent pas.
- Aucune dépendance extérieure : polices, images et scripts sont livrés dans le thème.

## Installation

**Depuis le Market d'Azuriom** : dans l'administration, ouvre **Thèmes**, cherche Nebula Limeris et clique sur **Installer**.

**À la main** :

1. Crée le dossier `resources/themes/nebula-limeris` sur ton site Azuriom.
2. Décompresse le zip dedans : le fichier `theme.json` doit se trouver directement dans ce dossier.
3. Dans l'administration, ouvre **Thèmes** et clique sur **Activer** à côté de Nebula Limeris.

Clique ensuite sur **Configurer** pour régler le thème. Pour que le chiffre « en ligne » et l'adresse s'affichent, ajoute ton serveur dans **Serveurs** et choisis-le comme serveur par défaut.

## Configuration

Tout se règle dans **Thèmes > Nebula Limeris > Configurer**.

### Apparence
- **Fond du site** : Abysse bleu, Nébuleuse violette, Aurore émeraude, Braise, Aube rose, Champ d'étoiles, ou aucun.
- **Opacité des blocs** : légère, moyenne ou forte.
- **Forme** : angles droits, légèrement arrondis ou très arrondis.
- **Police des titres** : condensée, large ou technique.
- **Couleurs d'accent** : une pour le mode sombre, une pour le mode clair.
- **Mode sombre par défaut** pour les nouveaux visiteurs.

### Navigation
- Afficher le logo du site à côté du nom.
- Garder le menu visible pendant le défilement.
- Laisser ou non les visiteurs changer entre clair et sombre.

### Haut de l'accueil
- Grand titre (vide : le nom du site), taille du titre, phrase d'accroche.
- Adresse du serveur (utilisée seulement si aucun serveur par défaut n'est choisi) et version du jeu.
- Bouton « Voter », bouton supplémentaire libre, chiffres affichés.

### Sections de l'accueil
- Actualités, objectif de votes, meilleurs voteurs (3, 5 ou 10), liste des serveurs, « Rejoindre en une minute ».
- Lien d'invitation Discord (vide : le bloc est masqué).

### Pied de page
- Texte de présentation, réseaux sociaux d'Azuriom, liens libres.

## Mise à jour

Remplace le dossier `resources/themes/nebula-limeris` par la nouvelle version. Tes réglages sont conservés par Azuriom.

## Désinstallation

Active un autre thème dans **Thèmes**, puis supprime Nebula Limeris depuis la même page.
